# DESIGN.md

# VIRUS404BEATS — DESIGN SYSTEM

STATUS = LOCKED

STYLE =
Maximalism

* Grid Brutalism
* Editorial Music Collage
* Raw Print / Street Poster
* Digital Audio Interface
* Controlled Chaos

## 0. CORE RULE

This design is NOT:

* generic SaaS
* clean/minimal portfolio
* glassmorphism
* soft neumorphism
* luxury black/gold
* Spotify clone
* sterile agency UI
* empty whitespace-first design
* rounded-card ecosystem

This design IS:

* rough
* dense
* layered
* asymmetrical
* tactile
* editorial
* music-first
* high-contrast
* noisy
* humanized
* rebellious
* professional
* usable

CORE FEEL =
record sleeve

* studio wall
* photocopied zine
* street poster
* audio workstation
* artist archive
* digital music player

KEY RULE:

CHAOS IN DECORATION.
CLARITY IN INFORMATION.

Roughness must feel intentional, not broken.

---

# 1. VISUAL PERSONALITY

PRIMARY = raw + aggressive + confident
SECONDARY = technical + editorial + underground
TERTIARY = professional + usable + trustworthy

Allow:

* overlap
* offset
* rotation
* torn edges
* tape
* scribbles
* scratches
* uneven spacing
* irregular crops
* imperfect borders
* collage stacking

Do NOT allow:

* unreadable hierarchy
* random semantic placement
* broken navigation
* CTA obstruction
* uncontrolled animation
* visual noise over essential content

Do not "clean up" the design into a conventional portfolio.

# 2. COLOR

BLACK
`#050505`
Background / rail / deepest panels.

NEAR BLACK
`#090909`
Hero / panels / cards.

OFF-WHITE
`#EEE9DF`
Primary text / major labels.

PAPER
`#D8D3C8`
Notes / pasted sheets / labels.

PAPER DARK
`#B9B3A8`
Secondary paper.

RED
`#F72B1B`
Primary accent and action color.

RED DARK
`#C7190E`
Secondary red / deep marks.

GRAY
`#77736B`
Metadata / low-priority text.

LINE
`#3B3934`
Borders / grid / separators.

COLOR PRIORITY =
black > off-white > red > paper > gray

Red is structural, not occasional.

Use red for:

* active nav
* active track
* CTA
* tape
* labels
* markers
* waveform
* important numbers
* handwritten marks
* selected states
* hover emphasis

Do not turn the entire interface red.

# 5. IMPERFECTION

Desired:

* rotation ±1–3°
* offset positions
* torn edges
* irregular sticker placement
* uneven paper width
* overlapping labels
* imperfect cropping
* hard shadow offsets
* handwritten placement
* micro-jitter

Decorative randomness is allowed.

Never randomize:

* nav order
* content meaning
* CTA usability
* accessibility labels
* form controls
* primary information

Humanization belongs mainly in decorative layers.

# 24. MOTION

Motion = physical + reactive + energetic.

Good:

* marquee
* waveform animation
* spectrum
* progress
* hover translation
* image scale
* parallax
* glitch reveal
* scramble text
* split text
* cursor magnetism
* scroll reveal
* distortion

Avoid:

* constant slow floating
* luxury fade everywhere
* heavy spring physics
* loading screens
* constant background motion

Suggested:
micro = 80–180ms
hover = 120–240ms
media = 300–550ms
section reveal = 400–800ms
marquee = continuous

---

404

# 26. ANIMA-STYLE EFFECTS

Allowed:

* image displacement
* RGB offset
* noise transitions
* hover distortion
* cursor-follow
* scroll velocity
* clip-path reveal
* glitch transition

Do not overload the page with simultaneous effects.

---

# 27. CURSOR

Desktop:

* small red outlined ring
* expands on interactive elements
* optional crosshair/noise trail

Do not create a huge cursor that blocks content.

Mobile:
custom cursor OFF.

---

# 28. SCROLL

Scroll should feel like moving through an archive.

Use:

* section boundaries
* persistent rail
* marquee separators
* oversized headings
* strong media moments
* controlled reveals
* optional sticky player
* section numbers

Do not turn the whole page into one continuous cinematic animation.

---

# 29. RESPONSIVE

DESKTOP:

* fixed rail
* dense hero
* huge type
* multi-column content
* visible player

TABLET:

* smaller rail
* reduced media
* preserve collage

MOBILE:

* top/compact nav
* horizontal nav
* stacked collage
* still oversized typography
* portrait remains dominant
* stickers/notes remain layered
* content may become single-column

Mobile must NOT become visually minimal.

Simplify geometry, not personality.

---

# 30. SPACING

Base:
8 / 12 / 16 / 24 / 32 / 40 / 64px

Large:
80px+

Normal UI = practical spacing.
Collage = overlapping/negative spacing where intentional.

Avoid excessive whitespace.

Blank space must create tension or hierarchy.

---

# 31. DENSITY

Target = medium/high density.

Major viewport should usually include:

* primary content
* metadata
* supporting graphics
* texture or visual layer

Avoid:
heading + paragraph + lonely image.

Large statement-only section is allowed when intentional.

---

# 32. ACCESSIBILITY

Visual style never overrides usability.

Required:

* semantic HTML
* keyboard navigation
* visible focus
* accessible names
* sufficient contrast
* meaningful image alt
* usable audio controls
* reduced-motion support

Reduced motion:

* disable cursor trail
* reduce glitch
* reduce parallax
* preserve core interaction

---

# 33. PERFORMANCE

Maximalism != heavy payload.

Prefer:

* CSS textures
* SVG technical marks
* optimized images
* WebP/AVIF
* lazy non-critical images
* small client islands
* targeted animation

Avoid:

* huge decorative video
* huge unoptimized textures
* many animation libraries
* entire-page client rendering

---
